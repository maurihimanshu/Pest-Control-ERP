# observability-structured-logging
## Purpose
Skill for structured logging. Cover: SLF4J + Logback, JSON log format (Logstash encoder), correlation ID in MDC, log levels, NEVER log PII/passwords/tokens/payment data, business event logging pattern.
## Expected Outputs
